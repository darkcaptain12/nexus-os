# @apex-os/memory

Memory engine interfaces for embeddings, knowledge storage, context management, and conversation history.

## Memory Types

- **Embedding** — Vector representations for semantic search
- **Knowledge** — Structured knowledge items with tags
- **Context** — Token-limited context windows
- **Conversation** — Chat turn history
- **Document** — Chunked document storage

## Exports

- `MemoryStore` — Storage interface
- `MemoryEntry`, `MemorySearchResult` — Data types
- `EmbeddingVector`, `DocumentChunk` — Specialized types
