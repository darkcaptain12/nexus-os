# @apex-os/notifications

Multi-channel notification system interfaces.

## Channels

- **Push** — Mobile/web push notifications
- **Email** — Transactional and marketing emails
- **SMS** — Text message notifications
- **Desktop** — Native desktop notifications
- **Webhook** — HTTP callback notifications

## Exports

- `NotificationProvider` — Channel provider interface
- `NotificationRouter` — Multi-channel routing
- Channel-specific notification types
