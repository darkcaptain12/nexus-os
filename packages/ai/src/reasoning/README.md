# Reasoning Engine

Structured reasoning with chain-of-thought, tree-of-thought, reflection, critique, verification, and risk assessment.

## Methods

- **Chain** — Linear step-by-step reasoning
- **Tree** — Branching exploration with evaluation and pruning
- **Reflection** — Self-critique and iterative improvement
- **Debate** — Multi-perspective argument
- **Verification** — Claim validation with evidence

## Features

- Confidence scoring per step
- Risk assessment for planned actions
- Verification against known facts
- Iterative reflection loops
