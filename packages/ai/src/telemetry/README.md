# Telemetry

Observability for AI operations — execution logging, performance monitoring, cost tracking, and alerting.

## Metrics

- **Performance** — Latency percentiles (p50/p95/p99), throughput
- **Cost** — Per-provider, per-model, per-agent cost breakdown
- **Tokens** — Input/output/total token usage
- **Errors** — Error rates, types, retry success rates
- **Alerts** — Threshold-based anomaly detection
