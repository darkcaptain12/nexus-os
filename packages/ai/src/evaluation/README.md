# Evaluation

Quality assessment for AI outputs — accuracy, relevance, hallucination detection, success tracking, and failure analysis.

## Metrics

- **Accuracy** — Correctness against expected output
- **Relevance** — Alignment with user query
- **Completeness** — Coverage of requirements
- **Coherence** — Logical consistency
- **Safety** — Compliance with safety policies
- **Confidence** — Self-assessed certainty
- **Hallucination** — Claims not grounded in context
