# Prompt Engine

Prompt template management with versioning, composition, injection, and testing.

## Prompt Layers

- **System** — Core system behavior and constraints
- **Developer** — Module-specific instructions
- **User** — End-user input
- **Memory** — Injected memories and context
- **Context** — Session and environment context
- **Tool** — Available tool descriptions

## Features

- Template registration with typed variables
- Version control with rollback
- Composition of multi-layer prompts
- Memory and context injection
- Prompt testing with constraints
