# Tool Registry

Universal tool system for AI agents — registration, execution, validation, permission checking, and health monitoring.

## Tool Categories

- **filesystem** — File read/write/search
- **github** — Repository operations
- **supabase** — Database queries
- **browser** — Web scraping, page interaction
- **desktop** — System automation
- **email** — Send/read emails
- **calendar** — Calendar management
- **trading** — Market data, order execution
- **shopify** — E-commerce operations
- **http** — Generic HTTP requests
- **mcp** — Model Context Protocol tools
- **custom** — User-defined tools
