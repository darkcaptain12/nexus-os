# Planning Engine

Goal decomposition into executable task graphs with dependency tracking and progress monitoring.

## Pipeline

1. **Goal** → High-level objective with success criteria
2. **Plan** → Ordered set of tasks with dependencies
3. **Task** → Agent-assignable unit of work
4. **Subtask** → Atomic step within a task

## Features

- Goal-to-task decomposition
- Dependency graph generation
- Plan optimization and parallelization
- Duration and cost estimation
- Progress tracking with completion percentage
