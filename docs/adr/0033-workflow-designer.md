# ADR-0033: Workflow Designer UI

## Status
Accepted

## Context
Users need to create, edit, enable/disable, and run workflows from the dashboard. A visual designer makes complex workflows accessible.

## Decision
Implement a Turkish-language workflow management page at `/workflows` with three tabs: active workflows (run/pause), templates (create from), and execution history. Templates provide 7 production-ready starting points.

## Templates
Morning Briefing, EOD Summary, GitHub Daily Check, Gmail Inbox Summary, Weekly Productivity Report, Calendar Reminder, Desktop Idle Notification
